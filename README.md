# rapidVarthalu 📰

rapidVarthalu is a modern real-time multilingual news web application that delivers the latest headlines from various categories including technology, business, health, sports, science, and entertainment.

The application uses NewsAPI for live news updates and provides a clean, responsive, and interactive user experience with features like dark mode, article bookmarking, category filtering, trending headlines, and search functionality.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* REST API Integration
* NewsAPI
* LocalStorage

## Features

* Real-time news updates
* Trending headlines marquee
* Dynamic category filtering
* Search functionality
* Bookmark/save articles
* Responsive design
* Dark mode support
* Loading animations
* Glassmorphism UI
